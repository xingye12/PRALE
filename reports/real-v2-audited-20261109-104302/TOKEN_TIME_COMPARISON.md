# 读取失败原因与 token / 耗时对照

本报告直接重算四个 raw.json；未调用模型。warm 为保留记忆，cold 为逐题空记忆。

## 读取失败的具体机制

- 基础 warm 的 8 次失败全部把 content_hash 或加连字符后的 hash 当作 scene_id；正确 ID 是独立的 UUID。两种字段同时出现在索引中，工具只接受 scene_id。失败返回通用 unavailable 文案，没有指出“传入的是 hash”，模型又尝试给 hash 加连字符，连续失败。
- 进阶 warm 的 3 次失败全部读取旧场景 `8f0e0c78-7292-4e2a-800b-9dc16ae73a0a`。该场景合并后为 dormant，但仍出现在注入索引中；read_scene 只接受 current，因此拒绝。索引缺少可读集合过滤，也没有 merged-to 重定向。
- 这 11 次均收到明确的工具错误回复，有可复核 ID/状态原因；没有证据把它们归因于 API 网络读取失败。
- 正文文件存在不等于当前工具可读，更不等于模型已经成功利用。基础成功读取 11/19，进阶成功读取 0/3。

## 如何解释

- total_tokens 是多轮 API 调用的累计输入+输出，包含重复上下文及缓存命中输入，不是单轮上下文长度，也不是百万 token 都按未缓存价格付费。
- warm 用量和耗时包含代理与记忆抽取/晋升调用；elapsed 还包含工具执行、队列排空和 oracle 验收。当前适配器未将 token 与耗时完整拆成代理/记忆/等待三部分，不能精确分摊各自贡献。
- 基础全样本平均代理轮次 cold 20.17、warm 17.92；warm 另有平均 5.33 轮记忆模型调用。进阶有用量样本中 cold 32.58、warm 28.82，warm 另有平均 1.82 轮记忆调用。超时任务的调用数与 token 同样缺失。
- 基础全样本平均输出 token 从 11,109 增至 31,483；因此“代理轮次更少”没有转化为总用量节省。进阶同题配对 token 仅减少约 0.9%，耗时仍增加约 40.1%。
- 读取失败和晋升重试都是实际观察到的开销来源，但现有指标不能将额外耗时精确归因给某一种原因。
- 每条件仅一次，样本相关；不做统计显著性或记忆因果收益声明。金额因未配置价格且存在用量缺失，不推算。

更多 L2 内容、dead-letter 与水位诊断见 MEMORY_DIAGNOSIS.md；原始任务判定见 RESULTS.md。

## warm 更慢的直接证据

以下为各题库同题、两组均通过的 11 对任务：

| 指标 | 基础 cold | 基础 warm | 进阶 cold | 进阶 warm |
|---|---:|---:|---:|---:|
| 每题 elapsed 秒 | 93.2 | 284.4 | 208.2 | 291.7 |
| 每题已成功返回的模型调用累计秒 | 84.3 | 216.4 | 192.0 | 212.4 |
| 每题代理模型轮次 | 20.73 | 18.36 | 31.73 | 28.82 |
| 每题成功返回的记忆模型轮次 | 0 | 4.55 | 0 | 1.82 |
| 每题输出 token | 11,106 | 30,013 | 25,427 | 28,497 |
| 每题未缓存输入 token | 37,132 | 122,261 | 60,716 | 115,872 |

- 运行器在 lane.drive 后同步 await `_promote`，完成记忆抽取与晋升后才返回；L1、L2 create/update/merge、L3 都可能增加独立模型请求，因此 elapsed 包含这部分时间。
- 两个 warm 数据库各记录 11 次 TimeoutError 尝试，合计 22 次。默认 provider 请求超时 60 秒，重试默认最多 3 次；耗时可被反复等待放大。尝试计数覆盖全部作业，不限于表中的 11 对通过任务。
- `_MeteredProvider.generate` 在请求成功返回后才 append：失败请求的等待时间未包含在 model_duration_ms，失败用量也未记录。因此 elapsed 减 model_duration_ms 不能直接解释为工具执行耗时或本地 CPU 开销。
- 已成功返回请求的模型时间，基础 warm 平均比 cold 多约 132 秒；进阶多约 20 秒。其余 elapsed 差仍混有失败请求等待、工具执行、适配器本地处理与 oracle，现有记录不支持精确归因。
- 代理轮次减少，但额外记忆调用、更多输出与更多未缓存输入，使节约未转化为总体提速。读取失败会产生局部无效往返，但没有逐工具独立耗时数据来精确量化其贡献。
